# תרגום עברית חי - Stremio Addon

אדון (addon) ל-Stremio שלוקח כתוביות אנגלית קיימות (מ-OpenSubtitles) ומתרגם אותן
לעברית באמצעות Google Translate (חינמי, לא רשמי), ומגיש אותן ישירות בתוך Stremio.

## איך זה עובד
1. כשאתה מפעיל סרט/פרק ב-Stremio, האפליקציה שואלת את האדון "יש לך כתוביות?"
2. האדון מוריד כתובית אנגלית מ-OpenSubtitles (המקור הכי פופולרי לכתוביות)
3. מתרגם אותה שורה-שורה לעברית (בבאצ'ים, כדי להיות מהיר ולא להעמיס)
4. שומר במטמון (cache) ומגיש את הקובץ המתורגם חזרה ל-Stremio

**חשוב:** בפעם הראשונה שסרט מסוים מתנגן, התרגום עלול לקחת בין כמה שניות לדקה
(תלוי באורך הסרט). בפעמים הבאות זה מיידי כי זה שמור במטמון.

## התקנה (חד פעמית)

### שלב 1: קבל מפתח API חינמי מ-OpenSubtitles
1. הירשם בחינם ב: https://www.opensubtitles.com/en/consumers
2. לך ל-"API Consumers" וצור אפליקציה חדשה
3. תקבל `API Key` - שמור אותו

### שלב 2: הגדר את הפרויקט
```bash
npm install
cp .env.example .env
```
ואז ערוך את `.env` והדבק את המפתח:
```
OS_API_KEY=המפתח_שלך_כאן
```

### שלב 3: הרץ את השרת
```bash
npm start
```
תראה הודעה שהשרת רץ על `http://127.0.0.1:7000`

## התקנה ב-Stremio
1. פתח את Stremio
2. לך ל-Addons (הפאזל בתפריט הצד)
3. למטה יש שדה "Search or paste addon URL" - הדבק:
   ```
   http://127.0.0.1:7000/manifest.json
   ```
4. לחץ Install

**אם Stremio רץ על מכשיר אחר (למשל טלפון) ולא על אותו מחשב שמריץ את השרת** -
תצטרך לחשוף את השרת החוצה (למשל עם [ngrok](https://ngrok.com)):
```bash
ngrok http 7000
```
ואז להשתמש בכתובת ה-ngrok במקום 127.0.0.1.

## מגבלות שכדאי לדעת
- **OpenSubtitles חינמי** מוגבל למספר הורדות ביום (בערך 20 ללא חשבון, יותר עם חשבון מאומת/VIP)
- **Google Translate הלא-רשמי** יכול להיתקע/להיחסם זמנית אם עושים יותר מדי בקשות ברצף - לשימוש אישי זה בדרך כלל בסדר
- התרגום הוא מכונה טהורה (ללא הקשר תרבותי) - איכות סבירה אך לא מושלמת

## מבנה הפרויקט
```
hebrew-live-subs/
├── index.js              # השרת הראשי - מגיש manifest + כתוביות
├── src/
│   ├── subtitleFetcher.js  # מוריד כתובית אנגלית מ-OpenSubtitles
│   ├── translator.js       # מתרגם SRT לעברית בבאצ'ים
│   └── cache.js             # שומר תרגומים במטמון מקומי
├── cache/                 # קבצי תרגום שמורים (נוצר אוטומטית)
└── .env                   # המפתח שלך (אל תשתף!)
```
